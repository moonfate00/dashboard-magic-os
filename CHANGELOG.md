# Changelog

All notable changes to Dashboard Magic OS are documented here.

## 0.1.0-alpha.0 - Unreleased

### Added

- Bilingual English and Simplified Chinese interface foundation.
- Portable `MagicOS/` storage profile and non-destructive compatibility with existing `Dashboard/` vaults.
- Brownfield-first folder mounts for indexing existing Vault libraries in place with cabin, role, and AI-scope policies.
- Shared record query and relation services for Organizer, Learning Threads, and People & Health.
- Read-only Organizer, Learning Threads, and privacy-projected People & Health applications.
- Visible but locked AI Steward shell with verified-entitlement, SecretStorage, usage, task, Provider, confirmation, and rollback safety boundaries.
- Durable AI change journals with atomic Obsidian persistence and a locked-state crash-recovery interface.
- Private-by-default personalization import and export with difference preview and explicit confirmation.
- Privacy, localization, packaging, and release audits.

### Release limitations

- This is a desktop-only alpha package for GitHub and BRAT testing.
- AI Steward actions remain disabled in the public package.
- Real Provider execution, paid entitlement verification, and AI-authored writes are not connected.
- Mobile support and Community Plugins directory submission remain pending.
